Manual Commands

For advanced users: You can also run these commands directly: 

# Populate all historical data
python manage.py populate_overview_summary --start-year 2023

# Populate specific month
python manage.py populate_overview_summary --month 2025-01

# Populate current month only
python manage.py populate_overview_summary --current-month

# Dry run to see what would be processed
python manage.py populate_overview_summary --dry-run --verbose

# Force refresh current month
python manage.py populate_overview_summary --current-month --force
